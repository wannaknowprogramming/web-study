# Лабораторная работа №2 — HTML, CSS, JavaScript и Ajax

Приложение получает список публикаций запросом `fetch` к JSONPlaceholder и выводит первые 12 публикаций. Есть поиск по заголовку и повторная загрузка данных.

## Запуск

Откройте `index.html` в браузере или запустите любой статический веб-сервер из папки `lab2`.
